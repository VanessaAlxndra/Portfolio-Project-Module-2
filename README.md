# Analisis Kata Kunci dari Ulasan Produk Fashion Wanita di E-Commerce

Proyek ini merupakan bagian dari Portfolio Module 02 dalam pembelajaran Data Science di Purwadhika. Fokus utama dari proyek ini adalah **analisis teks review pelanggan** pada sebuah toko pakaian wanita berbasis e-commerce, menggunakan **Natural Language Processing (NLP)**.

---

## Tujuan Proyek

1. Menganalisis sentimen pelanggan berdasarkan rating.
2. Menemukan insight dari review pelanggan dengan WordCloud.
3. Mengidentifikasi kata-kata yang sering muncul pada masing-masing kategori rating.
4. Menyimpan data hasil pembersihan ke Google BigQuery.

---

## Dataset

Dataset berasal dari Kaggle dan berisi ulasan pelanggan terhadap produk fashion wanita.

- Kolom yang digunakan:
  - `Title`: Judul review
  - `Review Text`: Isi ulasan
  - `Rating`: Nilai rating (1–5)
